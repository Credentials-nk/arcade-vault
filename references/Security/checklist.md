## Checklist de seguridad básico

Ver `specs/13-security-hardening.md` para el detalle completo de investigación y decisiones.

- [x] RLS: Row Level Security habilitado en ambas tablas: `games` y `scores` — ya estaba habilitado, verificado.
- [ ] Minimum password length — mínimo 8 caracteres. **Pendiente de dashboard** (no es código): Supabase → Authentication → Settings → Password → Minimum password length = 8. El input de `/auth` ya exige 8 en el navegador (`minLength={8}`), pero el mínimo real lo aplica Supabase Auth del lado del servidor.
- [ ] Leaked password protection. **Pendiente de dashboard**: Supabase → Authentication → Settings → Password → habilitar "Leaked password protection" (chequeo contra HaveIBeenPwned). Warning del advisor: `auth_leaked_password_protection`.
- [ ] Max signup rate — limitar signups por IP (anti-bot). **Pendiente de dashboard**: Supabase → Authentication → Rate Limits → configurar/verificar el límite de sign-ups por IP. Decisión (spec 13): se resuelve con el rate limiting nativo de Supabase, sin código de rate-limiting propio en la app.
- [x] Headers de seguridad en Next.js — agregados en `next.config.ts` (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, aplicados a todas las rutas vía `source: '/(.*)'`).

```ts
const securityHeaders = [
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'X-Frame-Options', value: 'DENY' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
];

// En la config de Next.js:
headers: async () => [{ source: '/(.*)', headers: securityHeaders }];
```
